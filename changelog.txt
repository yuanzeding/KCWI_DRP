1.0.0:
	-Release
1.0.1:
	-Added filter to remove bias frames with expime > 0 (bad focus images)
	-Config file adjusted to allow fits files of any name
	-Conda env file now explicitly describes channels to be used
	-Implemented astroscrappy for ccr, instead of lacosmicx
	-Added pipeline and script for running the DRP in real time at Keck
	-Changed logging to print more information about what files are being read when
	-Change ccdproc source to conda-forge to get latest version
	-Integrate TWIFLAT and DOMEFLAT frames into group mode
	-Enable recurring events option, allowing unordered files to be processed (sometimes)
1.0.2:
	-Changed headers in mflat and mbias to only store file names, not whole paths
	-Enabled -i CLI option
	-Fixed bug where bad pixels would cause entire slices to be masked, instead of single pixels
	-Added changelog

2026-11 (review fixes, YD):
	-RemoveCosmicRays.py restructured: one protection-mask loader (<frame>_intf_bcrmsk.fits,
	 1 = protect, read with == 1 and closed) and one astroscrappy runner shared by the first
	 and the extra pass; the duplicated read-noise/sigclip/history block is gone
	-The recovery-region path (<frame>_bcrmsk.reg un-masking pixels of a _crmsk.fits) is
	 removed; <frame>_bcrmsk.reg / _intf_bcrmsk.fits now has one meaning only, the
	 astroscrappy protection mask written by kcwi_automask --bcrmsk / kcwi_masksky_ds9_bcrr
	-Config booleans crmsk, extra_crr, bcrmsk are parsed the same way whatever form they
	 arrive in (ConfigClass returns section values as raw strings, attributes as typed values
	 or None); reduce_kcwi sets all three explicitly for both channels; the shipped kcwi.cfg
	 gains extra_crr and bcrmsk under [RED] and bcrmsk under [KCWI] (previously a missing
	 key gave KeyError: 'extra_crr' with -r, and crmsk = False had no effect)
	-FlagSaturation.py: boolean saturation mask, NSATFLAG is a pixel count (was a sum of
	 pixel indices), unknown camera falls back to 60000 ADU instead of an UnboundLocalError
	-np.cast["bool"] (removed in NumPy 2) replaced by .astype(bool)

2026-11-02 (58bd5bf, YD):
	-RemoveCosmicRays.py: the extra astroscrappy pass after a custom crmsk also receives the
	 protection mask, so a bright QSO core is not cleaned as a cosmic ray on the second pass
	-FlagSaturation.py: camera-specific saturation levels (blue 65534, red 62000 ADU)
	-MakeMasterFlat.py: edge-ratio clipping threshold 3 -> 20; a (disabled) dichroic-cutoff
	 block for the blue camera is present as `if False:` for future testing
	-flat_remove_crs step commented out in kcwi_pipeline.py, kcwi_pipeline1.py,
	 kcwi_pipeline_ff.py (no CR rejection on flats)
	-setup.py: numpy~=1.23.1, pandas~=1.5.3, keckdrpframework~=0.1.dev0, python_requires ~=3.11

2026-10-08 (4d7f9d8):
	-DAR_apply [cfg]: set False to skip the DAR shift for science frames (e.g. to apply DAR
	 while drizzling in KcwiKit); padding and DAR keywords are still written, DARCOR records
	 the actual state, standard stars are always corrected

2025-06-06 (757b7da, YD):
